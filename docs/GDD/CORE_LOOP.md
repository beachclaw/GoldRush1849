# Core Loop Design — GoldRush1849

## Primary Loop
```
Mine → Gold → Upgrade → Mine Better
```

## Mining Actions (v1.0)

| Tool | Method | Yield | Speed | Unlock |
|------|--------|-------|-------|--------|
| Pan | River (water required) | Low | Slow | Start |
| Pick | Rock face | Medium | Medium | Start |
| Shovel | Loose earth | Low | Fast | Start |
| Sluice Box | River channel | High | Continuous | 50g |
| Hydraulic Pump | Hillside | Very High | Automated | v1.2 |

## Resource Types
- **Gold dust** — base currency, early game
- **Gold nuggets** — rare, high value, discoverable
- **Gold ore** — requires processing (crusher/stamp mill)
- **Stone** — building material
- **Timber** — building material, from felling trees
- **Water** — critical resource, river/rain/water rights

## Secondary Loop
```
Earn → Build → Attract Workers → Scale → Earn More
```

## Progression Gates (v1.0)

| Unlock | Requirement |
|--------|-------------|
| Wooden sluice box | 50g gold dust |
| Tent → Cabin | 100g + timber |
| First worker | Cabin + 150g |
| General store access | Camp established |
| Mine shaft entrance | 500g + engineer |
| Railroad deal (v2 hook) | Operation phase complete |

## Risk/Reward

- **Floods** — destroy equipment, expose new veins
- **Cave-ins** — lose progress, open new tunnels
- **Dry spells** — river drops, panning harder
- **Vein depletion** — must prospect new areas
- **Rival prospectors** (v1.1) — claim jumping, contested territory

## The "One More Vein" Hook
Every dig has a chance to reveal something bigger.
The player always feels one swing away from a major find.
Tension: do you go deeper (risk) or bank what you have (safety)?

## Economy
- Gold → goods at general store
- Goods enable building and tools
- Workers cost ongoing gold (wages)
- Equipment degrades, requires repair/replacement
- Water rights can be purchased or contested
